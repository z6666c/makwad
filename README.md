# ملفات المحقق

لعبة تحقيق جنائي عربية: تفحص مسرح الجريمة بالمصباح، تستجوب المشتبهين، وتكشف كذبهم بالأدلة. اثنتا عشرة قضية في ستة مستويات، من السهل إلى الأسطوري.

يحتوي هذا المستودع على نسختين من اللعبة:

1. **نسخة الويب:** الملفات الموجودة في جذر المستودع. تعمل على GitHub Pages وتُثبَّت على الجوال كتطبيق (PWA)، وتشتغل بدون إنترنت بعد أول فتح.
2. **مشروع تطبيق المتاجر:** مبني على Capacitor، ومنه تُبنى نسخة App Store ونسخة Google Play.

---

## نسخة الويب

افتح `index.html` من أي خادم ويب. على GitHub Pages اتبع الخطوات التالية:

1. افتح **Settings ← Pages**.
2. اختر **Deploy from a branch**.
3. اختر الفرع والمجلد `/ (root)`.

تثبيتها على الجوال:

- **iPhone:** افتح الرابط في Safari، ثم اختر «مشاركة» ← «إضافة إلى الشاشة الرئيسية».
- **Android:** افتح الرابط في Chrome، ثم اختر «تثبيت التطبيق».

الخطوط موجودة داخل المستودع، فلا تحتاج اللعبة إنترنت بعد أول فتح.

## تطبيق المتاجر (iOS و Android)

### المتطلبات

| | iOS | Android |
|---|---|---|
| الجهاز | Mac عليه Xcode 15 أو أحدث | Android Studio على أي جهاز |
| الحساب | Apple Developer بـ 99$ سنوياً | Google Play Console بـ 25$ مرة واحدة |

وتحتاج كذلك Node.js 18 أو أحدث.

### البناء

```bash
npm install
npm run build          # ينسخ ملفات اللعبة إلى www/
npx cap add ios        # مرة واحدة
npx cap add android    # مرة واحدة
npm run assets         # يولّد الأيقونات وشاشة البداية من مجلد resources/
npm run ios            # يفتح المشروع في Xcode
npm run android        # يفتح المشروع في Android Studio
```

بعد أي تعديل على اللعبة شغّل `npm run build` ثم `npx cap sync`.

### ملفات التطبيق

| الملف | وظيفته |
|---|---|
| `capacitor.config.json` | اسم التطبيق `ملفات المحقق` ومعرّفه `com.makwad.mohaqqiq`. غيّر المعرّف لو أردت معرّفاً آخر قبل أول رفع، لأنه لا يتغير بعده |
| `resources/icon.png` | الأيقونة بمقاس 1024×1024 |
| `resources/splash.png` | شاشة البداية |

## قبل الرفع للمتاجر: الشراء داخل التطبيق

المتجر الموجود داخل اللعبة **تجريبي فقط**، فهو لا يخصم أي مبلغ. وApple وGoogle ترفضان أي تطبيق فيه شاشة شراء وهمية، لذلك يجب استبداله قبل الرفع بخيار من اثنين:

- **الخيار الأسهل: RevenueCat** عبر الإضافة `@revenuecat/purchases-capacitor`. تُعرّف فيه المنتجات (باقات الذهب الأربع وحزمة القضايا) مرة واحدة لكلا المتجرين.
- **أو الشراء الرسمي مباشرة:** StoreKit في iOS، وGoogle Play Billing في Android.

مكان التعديل في `index.html`:

- الدالة `confirmBuy(name, price, apply)` هي شاشة الشراء الحالية. استبدل محتواها باستدعاء الشراء الحقيقي، ونفّذ `apply()` فقط بعد نجاح الدفع.
- الدالة `openStore()` تعرض الباقات من `GOLD_PACKS`. اربط كل باقة بمعرّف المنتج نفسه في المتجر.
- احذف الملاحظة «وضع تجريبي» بعد التفعيل.

### نقاط أخرى تتطلبها المتاجر

- **زر «استعادة المشتريات»:** شرط من Apple لحزمة القضايا المميزة.
- **سياسة خصوصية برابط عام:** اللعبة لا تجمع بيانات، وتحفظ التقدم على الجهاز فقط.
- **التصنيف العمري:** موضوعها جرائم بدون عنف مصوَّر. التصنيف المقترح 12+ في App Store وTeen في Google Play.
- **صور العرض:** الجوال 6.7 و6.5 إنش، والآيباد 12.9 إنش. صوّرها من التطبيق نفسه.
