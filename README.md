# استوديو مكود

موقع شركة تطوير تطبيقات مع بوابة عملاء ولوحة إدارة.

- **الموقع:** https://makwad.com/
- **الواجهة:** React + Vite، تُبنى وتُنشر تلقائياً على GitHub Pages عند كل رفع إلى `main`.
- **قاعدة البيانات وتسجيل الدخول:** Convex (مستضافة عبر مشروع Macaly).
